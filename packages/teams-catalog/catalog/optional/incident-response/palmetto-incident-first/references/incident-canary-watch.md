# Incident Canary Watch Reference

This is a planning reference, not a `TASK.md`, routine, trigger, or executable hook. Paperclip
must not import or schedule it.

If the board later creates a separate routine, it should review newly assigned incident
tasks, flag missing identifiers, stale evidence, missing approvals, or concurrent work, and
leave one durable status comment. It must not produce an executive digest or dispatch
feature-delivery or machine-evolution work.
