# Knowledge and Extension Governance

## Hindsight

Use the existing Hindsight memory layer only as attributed context. Store the source system,
tenant, repository, commit or artifact identity, observation time, and retention class. Retrieve
memory as a lead, then verify mutable facts on the current acceptance surface. Memory cannot
authorize an incident closure, merge, deployment, purchase, credential use, or policy change.

## Graphify

Graphify is the preferred repository map when a current graph exists. Query it before broad
search, confirm critical paths against the current source, and update the graph after an approved
code change. Record repository and commit identity so a graph from one tenant, branch, or revision
is not treated as another's truth. A graph is navigational evidence, not runtime health proof.

## Skills

Skill evolution is proposal-driven. Capture the observed failure, source diff, version,
evaluation cases, permissions impact, and rollback. A different reviewer must approve it, and
activation happens in a later action. No role may write and activate its own governing skill or
instructions in the same run. This package installs no skill and grants no skill-creation right.

## Community candidates

The [awesome-paperclip](https://github.com/gsxdsm/awesome-paperclip) list is a discovery source,
not a dependency or trust root. Its company wizard, tracker syncs, Hindsight plugin, chat,
analytics, Obsidian, and MCP entries remain candidates until repository ownership, code,
release provenance, permissions, network behavior, maintenance activity, and uninstall path are
reviewed. Copy no credential or executable from the list into this package.

The [Hostinger Paperclip overview](https://www.hostinger.com/tutorials/what-is-paperclip-ai/)
supports the staged operating choice: start small with clear roles, monitor handoffs, and add
agents and integrations incrementally as complexity and cost grow. It is secondary guidance,
not evidence about this fork's runtime enforcement; the source and tests remain authoritative.
